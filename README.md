# Product Review Sentiment Analysis

A web application that analyzes customer product reviews using Natural Language Processing (NLP).

## Technologies Used

* Python
* Flask
* NLTK
* VADER Sentiment Analyzer
* Pandas
* HTML

## Features

* Upload product reviews in CSV format
* Classify reviews as Positive, Negative, or Neutral
* Fast sentiment analysis using VADER
* Simple and user-friendly interface

## Project Structure

Product-Review-Sentiment-Analysis

├── app.py

├── requirements.txt

├── reviews.csv

├── templates

│ ├── index.html

│ └── result.html

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run:
   python app.py

3. Open:
   http://127.0.0.1:5000
